QUICK FIXES
───────────────────────────────────────────────────────────────────────────
  Issue: "Cannot find module"
  Fix:   cd /vercel/share/v0-project && pnpm install

  Issue: MongoDB connection fails
  Fix:   Check server/.env MONGODB_URI

  Issue: Port 5000/5173 in use
  Fix:   Change PORT in server/.env
         Change port in client/vite.config.js

  Issue: Image upload fails
  Fix:   Create server/uploads/ directory
