📋 QUICK START (3 STEPS - 2 MINUTES)

Step 1: Configure MongoDB
━━━━━━━━━━━━━━━━━━━━━━━━━━
Open: /vercel/share/v0-project/server/.env

Add your MongoDB connection string:
  MONGODB_URI=mongodb+srv://username:password@cluster.mongodb.net/ecommerce
  JWT_SECRET=your_secret_string_here

GET MONGODB (FREE):
  → Visit: https://mongodb.com/cloud
  → Sign up (free tier available)
  → Create a cluster
  → Copy connection string to .env

Step 2: (Optional) Seed Sample Products
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  cd /vercel/share/v0-project
  pnpm run seed

Step 3: Run the Application
━━━━━━━━━━━━━━━━━━━━━━━━
  cd /vercel/share/v0-project
  pnpm run dev

✨ DONE! Both server and client will start.

❓ NEED HELP?

Issue: "Cannot find module"
→ Make sure you ran: pnpm install in root, server, and client

Issue: "MongoDB connection failed"
→ Check your MONGODB_URI in server/.env is correct

Issue: "Port already in use"
→ Change ports in server/index.js and client/vite.config.js

Issue: "Image upload not working"
→ Ensure server/uploads/ directory exists
